
## 12장. Vision AI(이미지): 분류를 넘어 검출·분할·문서/산업 적용까지 “현업형 컴퓨터비전”

### 1) 개요: Vision AI는 ‘보는 것’이 아니라 ‘측정·판정·추적’까지 포함한다

현업에서 Vision AI는 단순 이미지 분류보다 아래 과제가 훨씬 많습니다.

* **검출(Detection)**: 이미지에서 객체 위치(박스)와 종류를 찾기
* **분할(Segmentation)**: 픽셀 단위로 영역을 따기(불량/결함/인체/부품 경계)
* **추적(Tracking)**: 영상에서 동일 객체를 계속 따라가기(카운팅/행동 분석 전 단계)
* **문서/산업 비전**: 서류/영수증/도면/품질검사 등 “업무 자동화”와 직결

이 장은 “모델 이름 나열”이 아니라, **과제 선택 → 데이터 설계 → 모델/학습 → 평가 → 배포(지연/비용/엣지) → 운영**까지 한 흐름으로 잡습니다.

---

### 2) 학습 목표

1. Vision 문제를 **분류/검출/분할/추적** 중 무엇으로 풀어야 하는지 판단
2. mAP/IoU/Dice 같은 **핵심 지표**를 이해하고, 임계값/운영 기준을 설계
3. 최신 실무 모델(예: YOLO, RT-DETR, SAM 계열)과 적용 지점을 구분
4. 라벨링/데이터 편향/증강/에러분석으로 **성능을 올리는 루프**를 설계
5. ONNX/TensorRT/Triton 등으로 **서빙/엣지 배포**까지 고려한 제품 구성을 설명

---

## 3) 핵심 개념: Vision 과제 4종과 선택 기준

### 3.1 분류(Classification)

* “이 이미지에 결함이 있는가?”처럼 **이미지 전체에 라벨 1개**
* 장점: 라벨링이 비교적 쉽고 빠름
* 한계: “어디가 결함인지”를 못 보여줘 현업 설득력이 떨어질 수 있음

### 3.2 검출(Detection)

* 객체의 **바운딩 박스 + 클래스**
* 예: 안전모 착용 여부(사람/헬멧 박스), 불량 부품 위치, 매대 상품 카운팅
* 현업에서 가장 범용적

### 3.3 분할(Segmentation)

* 객체/결함의 **정확한 픽셀 영역**
* 예: 도장 결함 면적, 스크래치 영역, 의료 영상 병변, 배경 제거
* 품질검사/면적 측정/정밀 제어에 강함

### 3.4 추적(Tracking)

* 비디오에서 검출된 객체를 **프레임 간 동일 ID로 연결**
* 예: 출입 인원 카운팅, 동선 분석, 라인 상 물체 흐름, 안전 위반 감지

**선택 가이드(실무 요령)**

* “위치가 필요”하면 분류 말고 검출/분할
* “면적/경계가 필요”하면 분할
* “시간 축에서 개수/행동”이면 추적(검출이 선행)

## 4) 핵심 원리: 데이터가 성능의 대부분을 결정한다(데이터 중심 Vision)

### 4.1 라벨 품질이 곧 모델 한계

* 라벨 기준이 흔들리면 모델도 흔들립니다(결함 정의, 경계 기준, 박스 규칙 등).
* 현업에서는 **라벨 가이드(룰북)**가 모델 아키텍처만큼 중요합니다.

### 4.2 클래스 불균형과 “하드 케이스”

* 결함 검출은 보통 불량이 적습니다(극단적 불균형).
* 정상만 학습하면 “결함”을 잘 못 잡고, 결함만 늘리면 오탐이 늘어납니다.
* 해결은 모델보다 **하드 케이스 수집/증강/샘플링 전략**에서 나옵니다.

### 4.3 증강(Augmentation)의 실전 포인트

* 조명/노이즈/회전/크롭/블러/컬러 변화는 실제 현장 변동을 반영합니다.
* 단, 과한 증강은 “현실에 없는 데이터”를 만들 수 있어 성능을 망칠 수 있습니다.
* 원칙: **운영 환경에서 일어나는 변형만** 증강으로 넣기

---

## 5) 모델 패밀리(최신 실무 중심): 무엇을 언제 쓰나

### 5.1 검출: YOLO 계열 vs Transformer 검출(RT-DETR 등)

* **YOLO 계열(예: Ultralytics YOLO)**

  * 강점: 속도/배포 친화/레퍼런스 많음(현업 최우선 선택지인 경우가 많음)
  * 적합: 실시간 검출, 엣지 카메라, 빠른 PoC→제품화
* **DETR/RT-DETR 계열(Transformer 기반 검출)**

  * 강점: 전역 관계 모델링, 특정 세팅에서 안정적
  * 적합: 복잡한 장면, 구조적 객체 배치, 연구/고정밀 지향

### 5.2 분할: SAM 계열 + 태스크 특화 분할

* **SAM(Segment Anything) 계열**

  * 강점: 범용 분할(라벨링 보조/마스크 초안 생성에 특히 강함)
  * 활용: 라벨링 생산성 폭발(반자동 주석), 빠른 ROI
* **태스크 특화 세그멘테이션(U-Net류/Mask 계열)**

  * 강점: 특정 도메인(의료/결함/부품)에서 정확도 최적화
  * 활용: “픽셀 정확도”가 곧 품질 지표인 경우

### 5.3 백본(Backbone): ViT/ConvNeXt 관점

* 백본은 “이미지 특징을 뽑는 엔진”입니다.
* **ViT 계열**: 전역 관계 모델링, 대규모 학습에서 강함
* **ConvNeXt 계열**: CNN 장점 + 현대적 설계로 실무에서 성능/효율 균형이 좋음
  (실무에서는 보통 프레임워크가 백본을 포함한 모델을 제공하니 선택/튜닝이 핵심)

---

## 6) 평가 지표: Vision은 ‘정확도’ 하나로 끝나지 않는다

### 6.1 검출 지표

* **IoU(Intersection over Union)**: 예측 박스와 정답 박스가 얼마나 겹치는지
* **mAP(mean Average Precision)**: 다양한 IoU 임계값에서 정밀도를 종합한 대표 지표
* 현업 포인트: mAP가 높아도 “오탐/미탐 비용”이 중요하면 임계값을 조정해야 합니다.

### 6.2 분할 지표

* **IoU / Dice**: 픽셀 마스크 겹침 정도
* “면적 측정”이 목적이면 면적 오차(%)도 함께 봅니다.

### 6.3 운영 지표(진짜 중요)

* **오탐(False Positive) / 미탐(False Negative)** 비용
* **지연(latency), 처리량(throughput)**
* **프레임 드랍**, **엣지 디바이스 온도/전력**
* “정확도 1%”보다 “오탐 10건 감소”가 더 가치일 때가 많습니다.

---

## 7) 현업 파이프라인: 데이터 → 학습 → 배포 → 운영(루프)

### 7.1 데이터 수집/정제

* 카메라 위치/조명/각도/해상도 표준화가 성능에 크게 영향
* 운영에서 흔들리는 요소(빛 반사, 먼지, 렌즈 오염)를 미리 고려

### 7.2 라벨링 전략(최소 비용으로 최대 효과)

* 처음부터 완벽하게 라벨링하지 말고, **작게 시작→에러 분석→하드 케이스 추가**
* SAM 기반 반자동 분할, 검출 프리라벨링(초안 자동 생성)로 라벨링 비용 절감

### 7.3 학습/튜닝 포인트(실무 최소 세트)

* 입력 해상도/배치/학습률, 증강 강도
* 클래스 불균형 대응(샘플링/가중치)
* 과적합 감지(Train↑, Val↓), 데이터 추가가 우선인 경우가 많음

### 7.4 에러 분석(Error Analysis)

* 실패 케이스를 유형화해야 성능이 오릅니다:

  * 조명/반사, 모션 블러, 작은 객체, 가림(occlusion), 비슷한 결함 혼동
* “틀린 샘플 모음”이 다음 학습 데이터입니다.

---

## 8) 배포/최적화: Vision은 ‘현장 지연/비용’이 승부처

### 8.1 추론 최적화 스택

* **ONNX Runtime**: 다양한 환경에서 표준화된 추론
* **TensorRT**: NVIDIA GPU에서 최고 수준 최적화(특히 실시간)
* **양자화(8bit/INT8 등)**: 속도/전력 개선 vs 정확도 하락 트레이드오프

### 8.2 서빙/스트리밍

* **Triton Inference Server**: 모델 서빙 표준 플랫폼(배치/동시성/모니터링에 유리)
* **GStreamer/FFmpeg**: 실시간 영상 ingest/전처리 파이프라인 필수 도구

### 8.3 엣지(Edge) 배포 시 체크

* 카메라 입력 변동, 네트워크 끊김, 장치 발열/전력, 원격 업데이트(OTA)
* “모델”보다 **운영 환경**이 더 큰 변수가 됩니다.

---

## 9) 관련 기술·솔루션(실무에서 바로 쓰는 것들)

### 9.1 모델/프레임워크

* **Ultralytics YOLO**: YOLO 학습/추론/배포까지 경험적으로 가장 빠르게 굴리기 쉬운 생태계 중 하나.
* **MMDetection**: 검출/분할 연구-실무 모델이 폭넓게 모여 있는 프레임워크.
* **Detectron2**: Meta 계열 오픈소스 비전 프레임워크, 확장성과 레퍼런스가 풍부.
* **PyTorch**: 비전 연구/실무의 사실상 표준 학습 프레임워크.

### 9.2 데이터/라벨링/품질

* **Label Studio**: 이미지/비디오 라벨링 도구(검출/분할 모두 지원).
* **Roboflow**: 데이터 관리/증강/학습 파이프라인을 빠르게 구성하는 SaaS 성격 도구.
* **FiftyOne**: 데이터셋 시각화/에러 분석/샘플 탐색에 강한 도구.

### 9.3 전처리/증강

* **OpenCV**: 이미지/비디오 처리의 표준 라이브러리.
* **Albumentations**: 비전 증강 라이브러리(현업에서 매우 많이 씀).

### 9.4 배포

* **ONNX Runtime / TensorRT / Triton**: 서버·엣지 추론 최적화/서빙의 대표 스택.

## 10) 권장 실습(현업형): “보이는 데모”를 넘어 “운영 가능한 프로토타입” 만들기

### 실습 A: 실시간 검출(안전모/불량/카운팅)

1. YOLO로 검출 모델 학습(10~20클래스 이내 권장)
2. mAP뿐 아니라 **오탐/미탐 비용 기반 임계값** 설정
3. 스트리밍 입력(카메라/영상)에서 FPS/지연 측정
4. 결과를 JSON 이벤트로 출력(시간/클래스/위치/신뢰도)

**산출물**: 운영 기준표(임계값, 기대 오탐/미탐, FPS)

### 실습 B: 결함/영역 분할 + 면적 측정

1. SAM으로 라벨링 속도 개선(마스크 초안 생성)
2. 태스크 특화 분할 모델로 성능 최적화
3. Dice/IoU + 면적 오차(%) 평가
4. 리포트 자동 생성(결함 면적/위치/등급)
