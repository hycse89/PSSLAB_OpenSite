Hybrid xLM

거대 언어모델과 소형 언어모델의 완벽한 오케스트라

목적에 맞는 최적의 언어모델(LM) 활용

Hybrid xLM은 특정 작업에 가장 적합한 언어모델을 선택적, 전략적으로 사용하는 솔루션입니다. ChatGPT와 같은 거대 언어모델(LLM)부터 기업 내부의 소규모 언어모델(SLM)까지, 각 모델의 장점을 극대화하는 완벽한 오케스트레이션을 제공합니다.

PLM: 더 작고, 더 특화된 모델

AX²는 LLM/SLM의 조율을 넘어, PLM(Primitive/Personal/Pseudo Language Model)이라는 새로운 개념을 제시합니다. PLM은 특정 목적에 맞춰 SLM을 미세 조정(Tuning)하거나 재구성한 경량화 모델로, 더 높은 효율성과 정확성을 제공합니다.
